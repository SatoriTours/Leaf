# Leaf 图形实验室

真实 Windows/Direct2D 入口：`examples/graphics_lab/main.nim`。复用现有 Nim 2.2.6/MinGW SDK，按 `docs/windows-environment.md` 构建；本例显式软件渲染、full motion。Linux headless 测试不等于 GUI。

## 功能

- 播放／暂停、1/120 周期单步、中点、归零；输入 0–100 百分比后 Enter 定位，非法文本不改变时间轴。
- Canvas 聚焦后：空格播放／暂停，左右键定位 ±5%，Home 归零。原生按钮支持 Tab／空格，输入框支持键盘。
- 演示包含16个场景对象及额外1个交互圆点。圆点可点击／拖动；“移动圆点”展示 center 过渡。拖动时直达，不让过渡追赶指针。
- 尺寸、透明度和三种负载可调；100／1000／10000 档位移除额外圆点。切回“演示16”恢复默认参数、圆点及时间轴。
- 窗口可缩放；Canvas 保持960×540逻辑坐标，实际像素尺寸依窗口而变。

## 冻结场景 v1

`scene.nim` 的 `newLabScene` / `frameAt` 与演示的 `sampledItems` 共用几何采样。默认 seed=0x1EAFC0DE，尺寸比例1，alpha=0.85，背景#101820；圆／矩形／封闭三角形按索引循环。每对象1个变换组＋1个图元：3N命令；每三角形move/line/line/close共4段。

| 对象 | 命令 | 路径段 |
|---:|---:|---:|
| 100 | 300 | 132 |
| 1000 | 3000 | 1332 |
| 10000 | 30000 | 13332 |

三类负载：
1. 固定帧：`frameAt`返回已封存帧。
2. 属性：路径／形状几何不变，只改变组变换和颜色；复用 sealed PathData。
3. 动态几何：改变半径／尺寸并重新构建三角形路径。

尺寸上限2可能产生重叠／边缘裁剪，是显式参数，不丢弃命令。默认尺寸的属性场景另有完整图元边界测试。SceneStorage封存后不变，不暴露可写引用；组件用显式identity snapshot安全共享，参数编辑替换整个Scene。场景最多10000对象，缓存一份固定帧及有界对象数据，不是通用全局缓存。

DSL可复用已封存路径：
```nim
path:
  geometry: sealedPath
  fill: "#5ED5B0"
```
geometry不可与路径命令或fillRule混用；规则已包含在PathData内。

## 测量边界

这是功能实验室，不是正式性能producer。组件演示会重跑所属view及Canvas DSL（固定帧模式也如此），含统计文字和键盘root绑定；`frameAt`的批量帧无交互绑定。两者命令数据相同，不能混称相同开销。

没有正式计时采集、JSON/CSV报告、环境相容性比较、5s预热／30s采样／3独立进程结果，也不报告显示FPS或GPU时间。它们是下一性能切片；高DPI、硬件GPU及视频效果对齐仍开放。正式测量必须关闭演示HUD、冻结物理像素尺寸及实际渲染模式。
