## 书架截图

当前未取得非提权的 Windows 交互桌面新证据。仓库首页暂不展示书架图；下方的 Notes 是另一个示例，不是书架的效果图。

1. 在获准使用的非提权 Windows x64 交互桌面，按[首页的书架命令](../../README.md#在-windows-跑起书架)构建。使用已有高 DPI 测试桌面（建议 150% 或更高；记录窗口实际 DPI，例如 144 DPI），不改共享桌面的显示或认证设置。
2. 运行 `.\target\LeafBookshelf.exe`，核对初始四本书。用原生输入框输入 `设计`，核对只剩《设计心理学》和《写给大家看的设计书》，各自作者另起一行。清空后核对四本恢复，再输入 `设计`，保留输入框焦点、不选中文字。
3. 截取真实窗口可见边界，保存无损 PNG。正常关闭后用**同一个 EXE**加 `--dark` 启动，按同样步骤操作，保持同一数据、窗口尺寸、DPI、焦点和搜索状态，再截第二张图。不重绘、不放大、不把代码粘进图片。记录日期、源码版本（含未提交的构建输入清单）、EXE SHA256、主题、窗口 DPI、PNG 尺寸和捕获方式。
4. 两张图齐备并经视觉核对后，才在首页“我的书架”中、源码节选之前加入 `picture`，按页面主题切换，默认浅色，图片显示宽度约 600 px 并提供原图和来源链接。在实际 GitHub 页面分别查看桌面及手机窄宽（例如 375 CSS px），核对搜索词、两条书名和作者仍可读、图不横溢、深浅主题匹配。实际交付前没有图，不留占位图或预先指向不存在的文件。

最小补证：同一构建的深浅两张高 DPI 实拍、筛选和清空的真实交互结果及来源记录，以及 GitHub 桌面／窄宽视觉检查。headless 仅检验状态，不是实窗证据。
