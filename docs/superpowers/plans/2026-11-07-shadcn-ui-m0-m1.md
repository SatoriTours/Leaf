# Leaf 标准组件 M0／M1 实施计划

> 执行方式：原会话连续实现、自测与修复，按 executing-plans／test-driven-development 执行；最后独立验收。项目核心优先：不创建空间、分支，不提交，不按文件拆派；不因内部计划重复审批。

**目标：**固定 shadcn Neutral 原生主题、typed 标准组件入口及基础表单展示。
**架构：**设计变量独立于平台，标准组件生成现有 Node；必要语义通过 typed 标准组件 sidecar 进入既有 Host 协议。Win32 按语义局部绘制，不接管 EDIT。
**技术：**Nim 2.2.6、现有 managed Runtime、Win32。
**设计：**[已批准方案](../specs/2026-11-07-shadcn-native-ui-design.md)。

## 全局约束
- 参考 shadcn-ui/ui@42f3bb63b46a69e52a24bd005cdc9ec15ba7a7b9、new-york-v4、Neutral。
- 原有系统／松石 API 和默认不变；不静默丢标准组件的必需语义。
- 普通代码沿当前 main／cwd 执行；保护原有未提交 Notes／皮肤等成果。
- 本机缺 Nim，使用既有 Windows Nim 2.2.6；不安装依赖或改变认证。
- 既有 VM 在任务开始前已运行，不当作本任务资源关闭。
- 验收缺环境明确阻塞；M0 原生视觉未闭合前不盲目扩展 M1。

## 审查重点
1. OKLCH 色域／NaN／透明合成输入不能产生无效颜色。
2. 标准组件 metadata 必须跨 hostCompatible 保留，未支持平台不能降级成普通控件。
3. 旧主题、枚举序号和旧布局语义不能被新主题尺寸污染。
4. 原生 EDIT 的光标、选区、IME 和多行模式不能因换肤重建／丢失。
5. 更新／失败／卸载后的 HWND、字体和绘制状态不能泄漏或引用退役对象。
