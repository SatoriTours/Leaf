01 / HIERARCHY

先有层次，再有装饰。

标题、输入、操作、状态分区明确。将技术探针收进高级选项，不再把所有控件平铺在窗口左上角。

02 / CONSISTENCY

不是换色，是统一规则。

间距、字体、边框与语义色共用 Token。表单、列表、提示和深色模式保持同一种视觉语言。

03 / CLARITY

截图，也应该一眼看清。

正式截图从真实 Windows 200% DPI 无损采集；展示宽度约 960px，附原图链接。此原型预览同样以 2× 输出。
