01 / HIERARCHY

先有层次，再有装饰。

参考 Linear 的克制层级，减弱侧栏装饰和过多分割线；主内容、操作与状态各就其位。

02 / CONSISTENCY

不是换色，是统一规则。

参考 Fluent 2 的操作层级，输入框 40px、操作按钮 32px，搭配 8px 间距；并列操作等宽，列表状态切换不跳动。

03 / CLARITY

截图，也应该一眼看清。

参考 Radix 的表面与语义色分层，深色模式回归中性灰；12px 说明文字和 2× 预览兼顾清晰度。
